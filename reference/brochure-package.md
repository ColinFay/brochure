# brochure: Multipage 'Shiny' Apps

Build natively multi-page 'Shiny' applications, serving content on
several endpoints instead of a single page. Pages are declared with
their own user interface and server function and are dispatched by URL
with 'routr', including parameterised routes. Redirections, request and
response middleware, and helpers to read and set cookies are also
provided.

## See also

[`brochureApp()`](https://github.com/ColinFay/brochure/reference/brochureApp.md)
to build an app,
[`page()`](https://github.com/ColinFay/brochure/reference/page.md) to
declare a page, and
[`vignette("brochure")`](https://github.com/ColinFay/brochure/articles/brochure.md)
to get started.
